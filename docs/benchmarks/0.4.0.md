# nexttext 0.4.0 benchmark

Generated: 2026-10-20 (UTC)

This report extends the Phase 2 harness with the experimental `semantic`
strategy, a cost measurement, and an embedding-similarity metric. It reuses the
checked-in 250-caption COCO sample and the 16-caption hard-case diagnostic set.
The decision memo at
[`docs/decisions/advanced-backends.md`](../decisions/advanced-backends.md)
interprets the results.

## Data

- **COCO sample:** the first 250 captions from the checked-in
  `tests/fixtures/coco_captions_sample.json`, which is itself the first 250
  captions of the 1,000-caption person-related sample documented in
  `docs/benchmarks/0.3.0.md`. Provenance is embedded in the fixture.
- **Hard cases:** the 16 hand-authored captions in
  `tests/fixtures/hard_cases.json` that isolate possessive/object `her`,
  subject-verb agreement, and contractions. This set is diagnostic, not a
  random sample.

## Method

For every caption and strategy:

1. Rewrite the caption with `nexttext.debias(..., strategy=name)`.
2. Check the original and rewritten text with LanguageTool `en-US`.
3. Count a caption as an **introduced error** when the rewrite has more
   LanguageTool matches than the original. **Resolved** is the opposite.
4. Record rewrite wall-clock time after a five-caption warm-up so that lazy
   model loading is not charged to every caption.
5. Record a SHA-256 of the full rewritten output so runs can be compared.
6. Embed the original and rewritten text with a **different** embedding model
   (`all-MiniLM-L6-v2`) from the one used by the selector, and report mean,
   minimum, and maximum cosine similarity.

The `default` and `nlp` rows reproduce the Phase 2 strategies. The `semantic`
row is the experimental embedding-assisted selector described in the decision
memo.

## Results: COCO, 250 captions

| Strategy | Changed | Introduced errors | Introduced rate | Resolved | Net change |
| --- | ---: | ---: | ---: | ---: | ---: |
| `default` (lexical) | 79 | 3 | 1.20% | 0 | +3 |
| `nlp` (spaCy) | 79 | 1 | 0.40% | 0 | +1 |
| `semantic` (experimental) | 79 | 1 | 0.40% | 0 | +1 |

The three lexical introduced errors are subject-verb agreement failures
(`they holds`, `they performs`) plus the intentional `themself` rewrite that
LanguageTool reports as a spelling issue. The `nlp` and `semantic` strategies
fix the two agreement failures; both retain the `themself` match. The
experimental strategy did not reduce the grammar-error count below `nlp`.

### Cost and determinism

| Strategy | Rewrite seconds | ms/caption | Output SHA-256 (first 16) |
| --- | ---: | ---: | --- |
| `default` | 0.00 | 0.02 | `4bf4749792f2bd00` |
| `nlp` | 0.41 | 1.64 | `8af6bfa7301179a0` |
| `semantic` | 1.03 | 4.10 | `6645b8f4d4c381b9` |

A second full run with the grammar backend disabled produced byte-identical
outputs: all three SHA-256 values matched. The experimental strategy changes
13 of the 250 `nlp` outputs, all by substituting neutral synonyms such as
`child` → `kid` and `people` → `individuals`.

### Semantic similarity

| Strategy | Mean cosine | Min | Max |
| --- | ---: | ---: | ---: |
| `default` | 0.9709 | 0.7737 | 1.0000 |
| `nlp` | 0.9708 | 0.7737 | 1.0000 |
| `semantic` | 0.9711 | 0.7737 | 1.0000 |

The mean gain over `nlp` is 0.0003 cosine points on an independent embedding
model. That is within the noise of a coarse similarity metric and does not
establish better meaning preservation.

## Reproduce

```bash
pip install -e ".[benchmark,dev,nlp,semantic]"
python -m spacy download en_core_web_sm

# COCO 250-caption run with grammar, similarity, and warm-up timing
python tools/benchmark_coco.py \
    --captions-file tests/fixtures/coco_captions_sample.json \
    --sample-size 250 \
    --strategy default --strategy nlp --strategy semantic \
    --grammar local \
    --similarity fastembed \
    --warmup 5 \
    --output benchmarks/results/0.4.0.json \
    --report /tmp/0.4.0-report.md

# Hard-case diagnostic run
python tools/benchmark_coco.py \
    --captions-file tests/fixtures/hard_cases.json \
    --strategy default --strategy nlp --strategy semantic \
    --grammar local \
    --similarity fastembed \
    --warmup 5 \
    --output benchmarks/results/0.4.0-hard-cases.json

# Offline smoke run without Java, spaCy, or embeddings
python tools/benchmark_coco.py \
    --captions-file tests/fixtures/coco_captions_sample.json \
    --sample-size 250 --strategy default --strategy nlp --grammar off
```

LanguageTool runs locally in this report. `--grammar public` uses the
rate-limited public API; `--grammar off` skips grammar checks.

## Limitations

- LanguageTool counts are a coarse fluency proxy. They do not measure bias
  removal or meaning preservation.
- The COCO sample is keyword-filtered, not an annotated person subset.
- `themself` is intentional in nexttext but flagged by LanguageTool, so the
  residual COCO error is partly a checker convention.
- The hard-case set is deliberately adversarial and small. Use COCO for
  prevalence and hard cases for capability.
- The similarity metric is a separate embedding model, but cosine similarity
  still measures topical overlap rather than semantic equivalence.
- Timings are single-process CPU measurements on one machine. They are useful
  for relative comparison, not as a service-level guarantee.
