# nexttext 0.3.0 benchmark

Generated: 2026-10-20 (UTC)

This report measures whether the optional `nlp` strategy reduces
grammar-breaking rewrites compared with the zero-dependency lexical path. All
numbers below were produced by the commands in this document; none are
estimated.

### Hard-case diagnostic set

The COCO sample contains few difficult pronoun constructions, so a second
hand-authored set isolates the cases the NLP path targets: possessive versus
object `her`, third-person singular verbs after a pronoun becomes `they`, and
contractions. The 16 captions live in `tests/fixtures/hard_cases.json` with
provenance. This set is diagnostic, not a random sample and not COCO.

## Method

For each caption, the benchmark:

1. Rewrites the original with the selected strategy (or keeps it unchanged for
   the baseline).
2. Runs LanguageTool `en-US` on both the original and the rewritten text.
3. Counts a caption as an **introduced error** when the rewritten form has
   more LanguageTool matches than the original. **Resolved** is the opposite.
4. Reports introduced errors divided by the number of evaluated captions.

LanguageTool is a general-purpose grammar checker, not a bias metric. In
particular, it flags `themself` as a spelling issue even though singular
`themself` is intentional. That contributes to the residual errors in both
strategies and is called out under limitations.

## Results: COCO, 1,000 captions

Baseline: 232 of 1,000 original captions already had at least one
LanguageTool match (23.2%). This is the captions' own error rate, not errors
introduced by nexttext.

| Strategy | Changed | Introduced errors | Introduced rate | Resolved | Net error change |
| --- | ---: | ---: | ---: | ---: | ---: |
| `default` (lexical) | 267 | 8 | 0.80% | 3 | +5 |
| `nlp` (spaCy) | 267 | 4 | 0.40% | 3 | +1 |

The NLP path halves the introduced-error rate (8 → 4 of 1,000 captions, a 50%
relative reduction) and reduces the net error change from +5 to +1. Both
strategies rewrite the same 267 captions; the difference is that the NLP path
repairs agreement in four of them:

- `"A girl smiles as she holds a cat..."` → `"A child smiles as they hold a cat..."` (lexical produced `they holds`)
- `"A skateboarder jumps into the air as he performs..."` → `"they perform..."` (lexical produced `they performs`)
- `"A man ... as he stands..."` → `"as they stand..."` (lexical produced `they stands`)

The remaining four NLP-path introduced errors are all `himself`/`herself` →
`themself` rewrites that LanguageTool reports as spelling. They are not subject
verb agreement failures.

## Reproduce

From a repository checkout:

```bash
# Optional stack used for this report
pip install -e ".[benchmark,dev,nlp]"
python -m spacy download en_core_web_sm

# COCO run (requires Java for local LanguageTool; network for the first fetch)
python tools/benchmark_coco.py --sample-size 1000 \
    --strategy default --strategy nlp \
    --grammar local \
    --output benchmarks/results/0.3.0.json \
    --report /tmp/benchmark-report.md

# Hard-case run
python tools/benchmark_coco.py \
    --captions-file tests/fixtures/hard_cases.json \
    --strategy default --strategy nlp \
    --grammar local \
    --output benchmarks/results/0.3.0-hard-cases.json

# Offline sample run without Java or network
python tools/benchmark_coco.py \
    --captions-file tests/fixtures/coco_captions_sample.json \
    --sample-size 250 --strategy default --strategy nlp --grammar off
```

LanguageTool can also run through the public API with `--grammar public`; that
backend is rate-limited and is not recommended for the full 1,000-caption run.
Use `--refresh` to ignore the caption cache.

Machine-readable reports are checked in at
`benchmarks/results/0.3.0.json` and
`benchmarks/results/0.3.0-hard-cases.json`. Caption caches are intentionally
excluded from version control; the checked-in 250-caption fixture provides an
offline smoke test.

## Limitations

- LanguageTool's match count is a coarse proxy. It does not understand the
  intended referent or whether a neutral rewrite preserves meaning.
- The COCO filter is keyword-based, not an annotated person subset. It can
  include captions with incidental keyword matches.
- `themself` is intentional in nexttext but flagged by LanguageTool, so the
  residual COCO errors are partly a checker convention.
- Results depend on the LanguageTool version and Java runtime. Pin both when
  comparing runs.
- The hard-case set is deliberately adversarial and small; use the COCO
  numbers for prevalence and the hard-case numbers for capability.
